Clustering from Scratch in NumPy: HAC, K-Means++, Medoids, GMMs and Spectral Cuts

How it was built

Part 1: Scoring a Clustering

Before building any clustering method, build the yardstick (PML 21.1.1). Turn data into dissimilarity matrices, count how a clustering and a reference labelling agree, and compute purity, the Rand index, the adjusted Rand index and normalized mutual information. Every later comparison in the project uses these.

Part 2: Hierarchical Agglomerative Clustering

Build the dendrogram of PML 21.2: merge the two closest groups until one remains, under single, complete and average link. Cut the tree at a height or a cluster count, derive single link from a minimum spanning tree in O(N^2), test which linkages survive a monotone transform of the distances, and reproduce the shape of Figure 21.4 on the real yeast gene expression data.

Part 3: K-Means and K-Means++

Build K-means (PML 21.3): Lloyd's alternating minimization of the distortion, D-squared seeding, and random restarts. Land on the local optima behind Figure 21.7 on the book's own dataset, then find out when K-means++ actually helps and when it makes no difference.

Part 4: Vector Quantization

Read K-means as a compression method (PML 21.3.3): count the bits of the codes and the codebook, quantize an image pixel by pixel and block by block, and measure how much spatial correlation is worth once the codebook is charged for.

Part 5: K-Medoids on Strings

Cluster data that has no mean (PML 21.3.5). Compute edit distances between DNA-like reads, run the Voronoi iteration and the PAM swap search on the matrix alone, and test the book's robustness claim against K-means with a few far outliers.

Part 6: Gaussian Mixtures

Move from spikes to volumes (PML 21.4.1). Implement the E step in log space and the M step for full, tied, diagonal and spherical covariances, fit the book's five-blob dataset, confirm on the data that hard EM with identity covariances is exactly K-means, and score each model with BIC.

Part 7: Choosing K

Compare the three ways of choosing the number of clusters in PML 21.3.7 on the same data: validation distortion, BIC and the silhouette. Reproduce Figures 21.11 and 21.13 and see which criterion finds the five true blobs.

Part 8: Spectral Clustering

Cluster with eigenvectors (PML 21.5). Build a similarity graph, form the three graph Laplacians, verify Theorem 21.5.1, recover the rings and spirals of Figure 21.19 where K-means scores zero, measure how much the result depends on the kernel width, and connect the normalized cut to a random walk.

Part 9: Binary Data and the Bake-Off

Cluster binary data with a mixture of Bernoullis (PML 21.4.2), then run every method in the project on the same eight datasets and score them with the adjusted Rand index. No method wins everywhere, and the table shows which one to use when.
